# Proyecto de CC: Satelite Grupo 1 2026/2027
    Biel Navarro, Laia Almira, Nicolás Sobrino

    Sistema de satelite capaz de leer datos de sensores como temperatura, enviarlos a una estacion de tierra para representarlos en una GUI con python y con la misma GUI enviar comandos de vuelta al arduino satelite.
## Version 1
    Lee datos de temperatura y representa los datos en un grafico incrustado en el GUI de python.
